# Shinpoko — 写真・動画エディタ

ブラウザだけで動く、プリクラ風の写真・動画加工アプリ。インストール不要、サーバー処理なし(撮影・編集データは端末の外に出ません)。

## できること

| 機能 | 内容 |
|---|---|
| フィルター | 26種類(ナチュラル/ふんわり/ゆめかわ/透明感/ミルキー/エモ/シネマティック/シティポップ/ヴィンテージ/ドット/ピクセル/ジオラマ/ぷっくり/きゅっ …)。実際の写真に当てたサムネイルで選べる |
| エフェクト | SNS で流行りの動くエフェクト: グリッチ/RGBずらし/VHS/平成レトロ/キラふわ/万華鏡/ミラー/ブラウン管/ライトリーク/ビートズーム/シェイク/デュオトーン(強さ調整つき。独自の WebGL シェーダー) |
| 調整 | 明るさ/コントラスト/あざやかさ/暖かさ/シャープ/ビネット |
| モザイク | なぞる/四角で囲む、モザイク/ぼかし、粗さ・ブラシ太さ調整、消しゴム、全体がけ |
| 書き込み(プリクラ風) | ペン(ふつう/ネオン/レインボー/キラキラ/ハート)、スタンプ、文字(ポップ/ネオン/ふちどり)、消しゴム、ひとつ戻す |
| フレーム | ポラロイド/ガーリー/ハート枠/キラキラ/プリクラ/レインボー/ネオン枠/フィルム/シネマ/日付入り + 動くオーバーレイ(ハート降る/キラキラ舞う/ゆき/ふわふわ泡) |
| 加工付きの動画撮影 | カメラのプレビューにリアルタイムで加工・テンプレートを適用したまま録画(マイク音声つき) |
| 動画の加工 | 手元の動画にフィルター・モザイク・書き込み・テンプレートを重ねて書き出し |
| カメラで写真 | 撮影した一枚をそのまま写真編集へ引き継ぎ |

## 公開(GitHub Pages)

`.github/workflows/pages.yml` が `main` / `master` / `claude/photo-video-editor` への push で自動デプロイします。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. push すると自動で公開される(Actions タブから手動実行も可)。`main` を作った場合は `main` への push でも公開
3. 公開URL: `https://<ユーザー名>.github.io/shinpoko/`(https なのでスマホのカメラも使えます)

## ローカルで動かす

ビルド不要の静的サイトです。

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

カメラ/マイクを使うには `https://` か `localhost` で開く必要があります(スマホで試すときは GitHub Pages や Netlify などに置くのが簡単です)。

## 補足・制限

- 動画への「モザイク」「書き込み」は画面に固定された位置で重なります(動く被写体を追いかけるトラッキングはありません)。
- 動画の書き出しは再生しながら録画する方式のため、動画の長さと同じ時間がかかります。書き出し中は画面を閉じないでください。
- 保存形式: 写真は JPEG、動画はブラウザが対応していれば MP4、なければ WebM。iPhone では共有シート経由で「ビデオを保存」できます。
- 解像度の上限: 写真は長辺 1920px、動画/カメラは長辺 1280px(スマホでの動作を軽くするため)。

## 構成

```
index.html        画面
css/style.css
js/app.js         読み込み・描画パイプライン・モザイク・書き込み・録画
js/filters.js     加工フィルター定義(glfx.js の組み合わせ)
js/templates.js   フレーム/動くオーバーレイ(Canvas で描画)
js/post.js        動くエフェクト(WebGL フラグメントシェーダー)
vendor/glfx.js    WebGL 画像エフェクト (MIT)
```
